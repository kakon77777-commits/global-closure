# Key & Door: small production example

Produce one playable offline grid level. The project contract is studio/game-contract.json; shared state is studio/world.json. Target: Windows browser, self-contained HTML. Each architect owns its role directory and new uniquely named handoff files; programming also owns the final index.html. Shared contract changes are proposals, not unilateral edits.

Design: make and use a compact level-production tool and check the stated reachability rules. Art: make and use a parameterized SVG production tool, deliver the five usable visual assets and inspect a preview. Programming: make and use the integration/build tool, consume those real outputs and deliver the playable game.

Do not publish or install anything from this example. Work only in this project. Keep the result small; no third-party runtime dependencies. Preserve actual evidence and unresolved limitations in each role's delivery note. Context messaging is optional; durable handoffs are the required resumption source.
