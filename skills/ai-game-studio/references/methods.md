# Method integration

Resolve installed skills by exact frontmatter names `global-first-completion` and `mssp-tdd-apr`. Do not hard-code the creator's installation paths. Use their actual instructions, applying each to its responsibility rather than nesting complete ceremonies.

- Global First Completion: complete the requested whole, connect the main path, concentrate validation, repair related failures together, and stop at scoped closure.
- MSSP × TDD × APR: one canonical project world, selective Lead/Twin observation, stable invariants, falsifying witnesses and claims bounded by evidence. The standard profile has two contexts.
- This skill explicitly extends that profile to the requested three game disciplines. Use two of the three as Lead/peer for the current issue; do not create six permanent contexts. Third-party workers remain task-local and bounded.
